# NSDE

Легковесная, событийно-ориентированная среда рабочего стола для X11, написанная на Rust. NSDE создан как альтернатива тяжелым компонентам окружений (таким как KDE Plasma) с фокусом на нулевое потребление ресурсов в простое, строгую модульность и безопасный скриптинг.

## Философия проекта

1. Только события, без таймеров. Панель не опрашивает систему. Единственный "таймер" — одноразовая попытка переподключения к мосту при потере связи.
2. Разделение ответственности. nspanel — "безликий" и быстрый рендерер, который ничего не знает о конкретных виджетах. Вся логика X11 и D-Bus сосредоточена в демоне nsbridge.
3. Безопасный Lua. Поведение виджетов программируется на Lua. Виджетам доступен только строго ограниченный API (рисование, математика, чтение данных из сокета). Прямой доступ к системе (D-Bus, X11, файлам) запрещен.
4. Минимум зависимостей. В ядре панели и моста используются только самые необходимые и быстрые крейты (x11rb, mlua, rustbus, tiny-skia и др.).

## Состав проекта

Проект разбит на независимые подпроекты (субмодули):

*   [nspanel](https://github.com/Vladgobelen/nspanel) — Легковесная панель задач. Отрисовывает буфер на основе событий от X11 и Unix-сокета. Поддерживает динамический layout.
*   [nsbridge](https://github.com/Vladgobelen/nsbridge) — Демон-мост. Собирает данные об окнах (X11), системном трее (D-Bus), находит и нормализует иконки приложений и отправляет готовые JSON-структуры панели через сокет.
*   [ns-widgets-lua](https://github.com/Vladgobelen/ns-widgets-lua) — Готовые Lua-виджеты (часы, таскбар, трей). Легко расширяются и настраиваются.
*   [nswm](https://github.com/Vladgobelen/nswm) — Экспериментальная заготовка собственного оконного менеджера (WM) на Rust.
